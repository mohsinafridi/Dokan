            (Reverse proxy)
            docker run -p 5050:80 -e "PGADMIN_DEFAULT_EMAIL=mohsin.azam@maqta.com" -e "PGADMIN_DEFAULT_PASSWORD=admin" -d dpage/pgadmin4



            2. Run Postgres Image as continer:
             docker run -d --name mypostgres -p 5432:5432 -e POSTGRES_PASSWORD=admin postgres
